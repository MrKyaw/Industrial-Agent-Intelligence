# About

Industrial Agent Intelligence is a portfolio project demonstrating the applied-AI
and agent-evaluation skills used to build trustworthy industrial agents:

- facility-grounded reasoning over telemetry, alarms, ontology, and knowledge;
- policy-checked tool use with risk tiers, roles, and audit;
- deterministic guardrails for grounding, citations, safety, and injection;
- behavioural evaluation with explicit graders and regression gating;
- feedback loops and drift detection.

It contains no proprietary data or confidential information. All facility data is
synthetic and generated by `scripts/generate_demo_data.py`.

## Review in five minutes

1. `python -m iai demo`
2. `python -m iai evals run`
3. Open `reports/evals/latest.html`
4. Read `src/iai/reasoning.py::_triage`
5. Read `src/iai/guardrails.py::evaluate_guardrails`
