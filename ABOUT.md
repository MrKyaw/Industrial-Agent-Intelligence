# About

Industrial Agent Intelligence is a portfolio project demonstrating the applied-AI
and agent-evaluation skills used to build trustworthy industrial agents. It is
designed to be reviewed quickly and to make every claim auditable.

## What it demonstrates

- Facility-grounded reasoning over telemetry, alarms, ontology, and knowledge.
- Policy-checked tool use with risk tiers, roles, and a tamper-evident audit log.
- Deterministic guardrails for grounding, citations, safety, and injection.
- Behavioural evaluation with explicit graders and regression gating.
- Feedback loops and drift detection.
- A read-only HTTP API and a self-contained HTML scorecard.

## Why it matters

Industrial operators do not need fluent paragraphs; they need to know which asset,
which measurement, which alarm, and what to check next, with the evidence attached.
This repository shows the layer that makes that possible and measures whether it
works.

## Design stance

- Evidence over fluency.
- Read before write.
- Refuse, then explain.
- Escalate uncertainty.
- Treat text as data.
- Measure behaviour.

## Review path

1. `python -m iai demo`
2. `python -m iai evals run`
3. Open `reports/evals/latest.html`
4. Read `src/iai/reasoning.py::_triage`
5. Read `src/iai/guardrails.py::evaluate_guardrails`
6. Read `tests/test_reasoning.py`

## Scope and limits

- All facility data is synthetic and generated by `scripts/generate_demo_data.py`.
- The reference agent is deterministic; production use needs an LLM planner.
- Root-cause ranking is heuristic, not a learned model.
- The condenser approach is a proxy because saturated condenser temperature is not
  in the reference dataset.
